## 💻 How to Run the Programs

1. Open the folder of the activity you want to review.
2. Locate the C++ source file (`.cpp`).
3. Open the file in a compatible C++ IDE or editor.
4. Compile and execute the program.
5. Provide the required inputs and verify the output.

A C++ compiler, such as GCC or an IDE with a configured C++ toolchain, is required.
