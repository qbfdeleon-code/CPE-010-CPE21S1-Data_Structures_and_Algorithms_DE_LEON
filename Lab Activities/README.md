
# Laboratory Activities — CPE 010

This directory contains laboratory activities, programming exercises, and assessment-related work for **CPE 010: Data Structures and Algorithms** at the Technological Institute of the Philippines (TIP).

The activities are organized by academic assessment period to make laboratory work easier to access, review, and manage.

```text

```

## 📚 Laboratory Organization

### Prelim
Focuses on introductory programming concepts and foundational topics leading into data structures and algorithm analysis.

Topics in the syllabus include:
- C++ programming review
- Abstract Data Types (ADTs)
- Arrays and linked lists
- Dynamic memory allocation
- Stacks using arrays and linked lists

### Midterm
Covers fundamental data structures and common searching and sorting techniques.

Topics in the syllabus include:
- Queues using arrays and linked lists
- Linear search and binary search
- Hashing
- Basic sorting algorithms

### Final
Focuses on non-linear data structures and algorithm performance analysis.

Topics in the syllabus include:
- Trees and binary search trees
- AVL trees and tree traversal
- Graphs and graph representations
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Theoretical and experimental algorithm analysis
- Time complexity classes

*The topics above summarize the course syllabus; they do not necessarily represent the exact contents of every folder.*

## 🎯 Purpose

- Apply course concepts through practical programming exercises.
