## 📚 Course Coverage

### Prelim
- C++ Programming Review
- Abstract Data Types (ADTs)
- Introduction to Data Structures and Algorithm Analysis
- Space and Time Complexity
- Arrays and Dynamic Memory Allocation
- Singly, Doubly, and Circular Linked Lists
- Stacks Using Arrays and Linked Lists

### Midterm
- Queues Using Arrays and Linked Lists
- Linear and Binary Search
- Hashing
- Basic Sorting Algorithms

### Final
- Tree ADT and Binary Search Trees
- AVL Trees and Tree Traversal
- Graph ADT and Graph Representations
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Theoretical and Experimental Algorithm Analysis
- Time Complexity Classes

## 🎯 Learning Objectives

This repository supports the development of skills in:

- Designing and analyzing efficient algorithms.
- Implementing data structures and algorithms using C++.
- Evaluating algorithm performance and computational complexity.
- Developing programs using good programming practices.
